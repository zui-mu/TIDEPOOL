# 泳池大厅下一版空间方向（待实施）

目标：冷白、空旷、极简、超出正常建筑尺度；以重复和尺度产生不安。

当前问题：低矮侧廊遮挡真实高顶；上层墙和横梁形成没有玩法用途的二层观感；过多水平分割和接缝削弱完整感。实际模型错位、共面重叠、法线及UV不一致应先在几何和材质层修复，后处理不能补齐这些问题。白带尚未得到单一来源结论，不视为已修复。

下一版建议：
1. 保留原版，另建场景变体。继续复用水位控制、信件触发、干区和相机。
2. 删除低侧廊、无用途的上层封板与装饰横梁，保留完整单层高厅。
3. 使用少量统一、通顶的巨柱。建议先试净高约22至24米、柱宽约1.8至2.2米，保持重复间距；用角色身高验证视觉尺度，不对整个场景统一缩放。
4. 用长泳池、重复柱列、远端单一小门组织视线；保留大量空白墙面，不加入随机平台和杂物。
5. 统一墙面、柱子和顶面的衔接方式：去掉可见共面重叠、未对齐饰面和无意的小缺口；统一瓷砖尺寸与接缝。
6. 先从出生点、池边低视角和干区做模型截图验证，再处理冷白柔光、反射与烘焙。
7. 建筑通过后同步屋顶渗水采样、高水位终点、碰撞、信件位置、逃离距离和干区；确保原流程仍可完成。

当前已完成：CameraFollow 防穿墙，并通过192个视角案例。当前尚未实施：上述结构重排与尺度调整。
